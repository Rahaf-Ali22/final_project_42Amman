⚡ Race condition: double withdrawal

A Race Condition occurs when multiple concurrent requests access and modify shared data without proper synchronization. In this scenario, two withdrawal requests read the same balance before either transaction updates it, allowing both withdrawals to succeed and causing an incorrect account balance.
